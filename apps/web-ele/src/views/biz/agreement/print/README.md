# 协议打印：入口与文件职责

业务打印模板是独立交付项，与流程图打印分别验收。当前排版积木、文档流和分页能力可以复用，字段目录、数据组装及默认样例仍来自模拟协议。真实样张、字段和业务状态没有由这些示例确定。接入边界和整改清单见[范围与业务接入盘点](../../../../../../../docs/platform-scope-and-coupling-audit.md)。

打印包含两条主要流程：编辑模板，以及把模板和协议数据组合成打印结果。

## 先找入口

| 想修改什么 | 文件 |
| --- | --- |
| 协议列表打开的打印预览、PDF 导出、打印 | `print-preview-dialog.vue` |
| 粘贴或查看打印数据 JSON | `print-data-json-dialog.vue` |
| 模板设计器的加载、保存、撤销、预览 | `designer/agreement-print-designer.vue` |
| 画布拖动、缩放和元素选择 | `designer/document-canvas.vue` |
| 数据绑定、列编辑、显隐和筛行 | `designer/print-inspector.vue` |
| 字体、颜色、表格边框、恢复默认样式 | `designer/print-style-panel.vue` |
| 字段列表和默认列 | `data/fields.ts` |
| 默认模板、加载与保存 | `template/agreement-template.ts`、`template/template-store.ts` |
| 表格计算、合并和打印结果处理 | `runtime/prepare-template.ts`，再跟进它调用的模块 |

## 起始版式与预览样例

- 新建时选择「完整示例模板」或「从空白开始」。完整示例分为两个内容区段：协议信息、条形码、房屋与补偿明细；奖励、固定表单、金额、条件正文及纸质签章留白。奖励区在没有奖励数据时隐藏，不预设筛除明细的规则。签章留白不是电子签名。
- 已保存模板保持原版式。在「页面设置与更多 → 载入起始版式」选择并应用；取消不修改，应用可撤销，保存后才持久化。更换版式保留当前预览数据和已配置的打印脱敏。
- 所有模板统一使用一份完整示例数据：2 条房屋、34 条补偿、3 条奖励，直接展示跨页与重复表头。在「编辑预览数据」查看数量，按需展开 JSON 自定义，或恢复完整示例。
- 自定义预览数据仅影响当前编辑会话，不随模板保存；重新打开始终使用同一份完整示例。正式打印使用传入业务数据。

## 目录职责

```text
print/
├─ designer/                    设计器、画布、属性面板和编辑对话框
├─ data/                        协议转打印数据、字段、格式、样例、脱敏
├─ template/                    默认模板、存储、元素定位和模板修改
├─ runtime/                     公式、筛行、合并、分页、回流、水印
├─ engine/                      hiprint 初始化、依赖和组件注册
├─ print-preview-dialog.vue     业务打印入口
├─ print-data-json-dialog.vue   设计和预览共用的数据输入框
└─ types.ts                     打印数据类型
```

测试跟随被测试模块放置，例如 `runtime/print-paper.test.ts` 检查纸张和分页。不要创建汇总所有内部函数的 `index.ts`；调用方直接导入具体模块，便于查找实现。

## 打印时，数据经过哪里

1. `print-preview-dialog.vue` 接收协议详情或用户输入的数据。
2. `data/build-print-data.ts` 将协议详情转换成打印数据。
3. 业务数据入口用 `data/print-sensitive.ts` 执行已有字段访问限制，查看数据 JSON 也使用允许提供的数据；`template/template-store.ts` 按编码加载模板。
4. `runtime/prepare-template.ts` 整理模板和数据，处理公式、显隐、表格规则及排版。
5. `runtime/document-renderer.ts` 按实际内容排版分页，`engine/document-print.ts` 将同一结果交给预览、打印和 PDF。

查“界面数据正确但打印不对”的问题，先看第 4 步的输入输出，再检查具体规则模块。

## 打印脱敏

工具栏「打印脱敏」统一管理本模板的字段输出规则；文本属性中可点击「设置打印脱敏」直接定位绑定字段，明细表和固定表单属性也提供入口。选字段 → 开启「打印时打码」→ 选全部隐藏、手机号、身份证、姓名或自定义保留位数 → 查看样例 → 应用到模板 → 保存。弹窗取消不写入，应用可撤销、重做，重新打开模板保留规则。

规则保存在模板根级 `agreePrintMaskRules`，只包含字段路径和脱敏方式，明细列使用 `houses.certNo` 等完整路径。`runtime/print-masking.ts` 在运行时建立字段依赖，文本、长文本参数、固定表单格子、明细表、合计、二维码和条形码共用输出脱敏。原值继续参与公式、筛选、排序和合并；直接字段按规则打码，引用脱敏字段的计算、汇总、拼接及已知派生结果统一显示 `***`。空值保持为空，短值不会因保留位数过大而泄露原文。固定文字和业务系统预先拼接但未声明依赖的自定义字段需单独检查、配置。

模板脱敏不配置角色或权限码。已有业务字段访问限制仍在数据入口执行，业务端已隐藏的值不会因关闭模板脱敏而恢复原文。本功能控制纸面输出，不替代接口的数据访问授权。

验收：给样例 JSON 加 `phone: "19112340005"`，添加多个手机号绑定和长文本参数 `{{phone}}`，将 phone 设置为手机号脱敏，画布与预览均显示 `191****0005`。给明细金额列开启全部隐藏，验证计算、筛行及跨页行数不变，金额和合计显示 `***`。保存重开，检查规则、打印与 PDF；取消、撤销、关闭脱敏分别验证草稿隔离、规则恢复和正常输出。

## 编辑时，怎样写回模板

`document-canvas.vue` 和属性面板通过设计器维护完整的模板 JSON。样式面板接收选中元素，提交 `patch` 事件；`print-inspector.vue` 用 `patchElementOptions()` 写回模板，再通过 `canvasPatch` 通知设计器更新。

因此，调整字体、颜色和边框时，只需从 `print-style-panel.vue` 开始。它自己管理表单草稿和选中元素切换，不依赖整份模板、接口或本地存储。

保存时直接使用设计器维护的完整 JSON，不再经过旧的 hiprint `getJson` 字段恢复流程。计算公式、颜色、合并等扩展信息仍保存在模板中，相关测试覆盖保存后的 JSON 往返。

## 两个设计入口都在使用

- `designer/index.vue` 是后台菜单通过字符串路径加载的独立协议设计器。没有静态 `import` 不表示它没用；此入口使用本地模板保存。
- 系统管理的 `system/print-template/edit.vue` 复用 `agreement-print-designer.vue`，通过模板管理流程保存到服务端。

不要只根据函数上的旧注释删除本地保存逻辑，也不要直接改变已有路由组件的路径。深拷贝统一使用协议目录下的 `clone.ts`；纯计算模块不需要为了深拷贝而导入存储或 API 模块。

## 编辑器操作与验收

- 默认优先显示画布。左侧「添加」打开内容库，「字段」打开可绑定字段；选择画布元素后右侧显示属性，也可用「元素」定位其他内容。
- 固定信息从「添加 → 固定表单」开始，重复记录从「添加 → 明细表」开始。点击字段或拖动始终新增元素；选中文本后，字段右侧的「绑定」只替换当前元素的字段。「已绑定」表示当前字段，无需重复绑定。右侧「选择字段」仍可替换绑定。
- 属性分为「内容与数据」「外观」「排版」「规则」。普通属性修改后更新画布；结构弹窗先编辑草稿，取消丢弃，应用到画布后可以撤销。
- 「正在编辑」说明目标与作用范围，随属性页签、数据列、表头选区或固定表单行列切换更新。结构弹窗显示「草稿 · 尚未应用」；应用后的提示明确要求保存模板。整列逐行公式与当前单格计算使用不同范围说明。
- 修改名称、编码、状态和备注使用顶部「模板信息」。顶部只保留一个「保存」，同时保存基本信息与版式；保存期间不能重复提交，保存失败可以重试，保存期间继续编辑的内容仍标记为未保存。
- 「编辑预览数据」只影响当前画布和预览，不保存业务数据。顶部「预览」显示实际页数、生成进度及失败后的重试入口。关闭预览后，旧请求不会继续写入结果。
- 设计器「预览 → 打印样张」打开浏览器打印窗口，可选择打印机或另存为 PDF。试打使用本次预览已生成的实例和数据，包含未保存的版式修改、分页和脱敏结果，无需先保存；示例数据仅供检查排版。生成中、生成失败或编辑预览数据时禁止试打，更换数据会先重新生成预览。
- 「页面设置与更多」收纳水印、模板 JSON、载入起始版式和删除当前区段。载入版式保留当前预览数据和打印脱敏，并可撤销。
- 撤销回最近保存的版式应显示「已保存」；再次修改显示「未保存」。弹窗打开或编辑页切换到后台时，画布删除、撤销和保存快捷键不应干扰当前操作。

建议验收顺序：修改文本绑定 → 撤销并检查保存状态 → 新增明细表 → 编辑结构后取消 → 再次编辑并应用 → 在外观中切换跨页表头 → 更换多页预览数据 → 预览 → 保存并重新打开。分别检查每页重复表头和只在第一页显示表头；恢复默认后重新选择元素，属性页签、数据编辑和预览应继续可用。

## 文档流布局（默认）

正文使用普通文档流和 flex 行列，文字实际高度由浏览器计算。同一行按最高内容占位，后续行自然顺延；正文无需回流组，也不再使用绝对坐标定位。

- 从左栏添加元素或字段时，按住拖动超过少量距离便显示跟随提示和纸面插入线，松手只新增一次；Esc 或拖出纸张取消。轻点仍按单击添加处理。文档流模式的左栏添加、纸面元素移动和两个拖动手柄统一使用指针事件，不依赖浏览器原生 HTML5 拖放；浮动手柄、列分隔线覆盖处也能识别纸面落点。
- 选中元素后，蓝色选中框贴着实际文字或表格。拖动「调间距」手柄时，绿色虚框预告落点并显示 pt / mm 距离；上拖可收紧到 0。达到最小间距后若需要跨过上一段，应改用「排序」手柄。
- 直接拖动未选中元素时，拖动期间不改变选中或插入工具条，松手后才提交并选中该元素，避免原生拖拽被布局更新取消。拖动结束产生的多余点击会被拦截，下一次正常点击不受影响。
- 拖动「排序」手柄时，蓝色插入线显示前后位置，空白处也会吸附到最近一行；靠近目标左、右边缘时提示插入它的左、右侧；同行换位保留各元素宽度，新加入同行时均分宽度。按 Escape 或拖出纸面可取消，拖动过程不写入模板，松开才产生一次修改。
- 选中同行元素后，拖动列间蓝色分隔线可调节相邻两列宽度，其他列不变；拖动中实时换行并显示百分比，松手后重新分页并记作一次修改，Escape 取消。分隔线获得焦点后可用左右方向键微调 1%，按住 Shift 调整 5%。
- 右侧「排版」提供向左/右换位、独占一行、宽度、靠左/居中/靠右、上方间距（mm）及清除间距。调整后保持选中；可用设计器撤销恢复。同行修改宽度数值会按比例调整其他列，分隔线则只影响相邻两列。
- 「上方间距」只调整当前元素。旧模板的整行间距和元素留白合并为同一个可编辑值；首次调整时将共享间距转为各元素自己的间距，同行其他元素的视觉位置不变。一般上限 200pt（约 70.6mm），旧模板更大的间距可逐步收紧。
- 「占正文宽度」控制宽度；独占一行时可选择靠左、居中、靠右。例如盖章区可独占一行靠右，或与签字同行后单独增加上方间距，正文增长时仍然跟随下移。
- 「隐藏后 → 移除空位」会移除该元素。整行隐藏后，不再占据该行高度及段前间距；同一行仍有可见元素时，保留它的列位置。「保留空位」按模板原来的设计高度保留空白占位。
- 「尽量与下一段同页」适合章节标题，减少标题单独留在页尾的情况。
- 正文超过纸张可用高度自动续页。普通段落尽量整段换页；超长段落按实际换行拆分；长表按行续页，表头是否重复由表格设置决定，单个单元格超过一页也能拆分保留文字。盖章和签字跟随正文，正常情况下整行换页。
- 「新增手工区段」和页面隔断明确要求后续内容另起一页。自动续页不会写入模板，不会因为更换样例数据改变保存的区段数。
- 正文左右和上边距为 20pt，下边距 40pt。页码、水印属于页面装饰，仍可使用纸面定位。

旧模板首次打开或打印时，由 `runtime/document-layout.ts` 把坐标转换为行、列宽、缩进和间距，写入 `options.agreeDocument`。保存后直接使用这些结构信息；原来的坐标和分组信息保留作兼容信息，不再控制正文排版。历史自由排版模板应在转换后检查同行关系及间距，调整满意后保存。

`runtime/document-renderer.ts` 负责共享的 DOM 渲染、字体测量和分页，画布、预览、打印及 PDF 使用同一份排版规则。`engine/document-print.ts` 只借用 hiprint 的打印及 PDF 输出能力。旧的 `canvas-stage.vue` 和回流模块保留给旧版内部调用及回归测试。

## 统一表格入口与编辑方式

左侧「添加」分别提供“明细表”和“固定表单”，单击新增，或直接拖到纸面指定位置。

- **明细表**：一个数组按列绑定并重复成行，适合房屋、补偿、奖励清单。保留多层表头、筛行、列计算、条件颜色、合并与表尾；可在“外观 → 表头 → 跨页表头”选择每页重复表头或只在第一页显示表头，旧模板默认每页重复。
- **固定表单（原自由表单）**：按单元格绑定，可混排固定信息与多个数据源的简单明细。默认附带协议编号、日期、房屋明细和合计示例；建筑面积使用 `row.buildArea`。

两种方式共用字体、颜色、适用的边框设置、字段选择和显示格式。整表外观统一在侧栏“外观”修改，显示条件统一在“规则”修改，弹窗不再重复。明细表按“数据来源、列与表头、合计与备注”组织设置；固定表单按“单元格、当前行、当前列”组织设置，数据源属于当前行。只展示当前方式实际支持的设置。

表头按列范围分组收进高级设置；样例默认折叠。合计在“合计与备注”勾选数值列，使用筛选后的全部明细，不是协议总金额。备注一键添加整行，自定义表尾保留在高级入口，按格点选编辑。画布合并工具跟随选区末端显示，不再占据页面顶部。

编辑窗口内先修改草稿，样例使用与打印相同的表格渲染规则，最多显示 12 行；完整分页使用快速预览。“取消”或关闭窗口丢弃草稿，“应用到画布”一次提交，设计器可以一次撤销；应用后仍需保存模板。画布侧栏直接修改样式/显隐仍即时生效。

两种方式保留原有模板数据结构，不自动相互转换。自由表单中的列标题目前是固定行，不会在续页重复，不能代替所有明细表功能。

自由表单配置：

- 固定格：选择“固定文字”填写标签，或选择“绑定字段”填写 `agreementNo`、`signDate` 等主字段；也可使用字段选择器。
- 动态行：在“本行数据源”选择 `houses`、补偿或奖励等数组。本行每个格子可绑定 `row.address` 等当前记录字段，主字段仍可直接绑定。一个表单可包含多个独立的动态行。
- 公式：序号使用 `index + 1`，明细金额可使用 `row.quantity * row.price`，汇总使用 `SUM(houses, "buildArea")`；金额、日期、大写金额等通过单格“显示格式”配置。
- 结构：点击格子，按住 Shift 点击另一个格子选择矩形后合并；支持固定区域横纵合并，以及动态行横向合并。合并显示左上格内容，拆分恢复被覆盖格内容。增删行列会调整合并范围。
- 动态行没有数据时，可保留一行空白或移除本行。后面的固定行、其他明细及合计自然顺延；所有行都被移除时，整张表不显示并遵循元素补位设置。
- 点击“应用到画布”更新组件，再保存模板；取消不会修改模板。整张表保留现有画布拖动、宽度调整、显隐、样式和分页能力。

配置保存在 `options.agreeFormGrid`。`runtime/print-form-grid.ts` 将运行时副本编译为原生表格列、独立数据数组、合并与样式信息，文档流画布和打印使用同一份数据。旧的普通表格不会被转换。

### 行高

- 高度的最小单位是整行，单元格用于定位行。所有高度均为最小占位（pt），长内容自动换行撑高，不裁剪文字；纵向合并格随其跨越的各行伸展。
- 固定表单：点画布格子，在浮动工具条“更多 → 行高设置”调整所在行；在“编辑固定表单格子”中也可输入高度，或拖动左侧行号下方的边界。方向键微调，Shift 加速，Esc 取消拖动。弹窗取消不改模板，应用后可撤销。
- 表单动态行：弹窗内的 `height` 是该模板行的默认高度。点画布中的某条展开记录，只调整该记录，并提供“恢复默认行高”；覆盖保存在模板行的 `recordHeights`，其余记录继续跟随默认值。
- 明细表：点正文格子只调整所在记录，覆盖保存在 `agreeBodyRowHeights`；“恢复默认行高”只删除当前记录的覆盖。“外观”中的 `tableBodyRowHeight` 是整表默认最小行高，修改默认值不影响已单独设置的记录。
- 单行配置优先关联原始数据中唯一的 `id`、`uuid`、`key` 或以 `Id`、`ID`、`_id` 结尾的标识字段；业务打印数据保留记录 `id`。没有标识时按唯一原始数据内容定位（忽略展示序号和运行时元数据）。匹配在公式、排序、筛选和序号重排前建立，原记录消失不会回退到同位置的新记录。内容完全相同且缺少唯一标识时禁用单行设置并提示补充 `id`；按内容匹配的记录内容变化后恢复默认值。
- 表头：单层沿用 `tableHeaderRowHeight`；多层在外观中逐行设置，覆盖值保存在 `agreeHeaderRowHeights`（下标对应从上往下的表头行）。未设置的行使用原默认值。续页重复表头保留相同高度。

验收：默认行高设为 24 pt，再将某条明细设为 40 pt，确认只有该记录变化；修改默认值，确认该记录仍为 40 pt；排序、筛选、保存重开后检查配置仍跟随原记录，再恢复该记录默认行高。给一条记录填入长文本，确认仅该记录自动撑高；用多页数据检查表头高度与合并格续页效果。

边界：一个动态行对应一条记录，不支持跨动态行的纵向合并或单条记录重复多行块。长表按文档流渲染器续页；表单内部的章节标题、明细列标题是普通固定行，暂不自动在续页重复。

### 画布单元格选择

单格选择突出当前格，整表边界弱化；范围选择使用浅蓝底色和外围边界，内部保留原来的表格线。点击表格容器空白处回到整表选择。工具条显示单格行列位置或多格范围，优先放在选区上方，并随滚动和缩放重新定位。

合并至少需要两个相邻单元格；拆分仅对单个手工合并格启用，列规则产生的自动合并仍在列规则中调整；单格计算需要选择一个绑定字段的格子。“更多”展开行高设置，说明会标明影响范围；只有展开时才淡色标记当前行。Escape 或点击外部关闭行高设置，关闭后仍保留单元格选择。

### 表格样式与边框验收

- “边框 → 表格外框”按上、下、左、右分别勾选，控制每个分页片段的外围。“下”就是表格最底部横线，不依赖是否有合计或备注行。
- 表头、明细、合计与备注分别设置“内部格子线”，只提供显示／隐藏两个状态，不再暴露存储层的默认值选项。表头与明细的分隔线、合计与备注前的分隔线各有一个入口，共享边界两侧同步处理，避免相邻单元格重新画线。
- 合计与备注是明细之后的内容行，包括自动合计与自定义备注，不代表表格底边。没有这类内容时隐藏其边框控件，保留添加入口提示；固定表单只展示外框与内部格子线。
- 新设置保存在 `options.agreeTableBorders`，其中 `outer` 保存四边的布尔值，`headerInner/bodyInner/footerInner` 控制内部线，`headerDivider/footerDivider` 控制分隔线。仅保存实际操作过的属性；没有设置的部分仍使用旧模板规则。
- 旧模板不自动改写、不改变已有输出。旧分区外框在左右边有差异时，复选框显示半选并提示；点击某一边后统一该边，其余旧设置保留。改字号、颜色或行高不应改写边框。保存重开保留布尔值 false；恢复默认样式同时清除新、旧边框字段，不改变字段、表头结构、合计与备注内容或跨页表头模式。
- 跨页后按当前片段重新计算边界，包括合并格截断与续页不显示表头的情况。画布、结构编辑样例、预览和打印共用文档流渲染器。
- 整表默认字号为 10 pt；表头字号留空跟随整表，默认粗体；文字最小行高至少为对应字号的 1.25 倍。单列颜色等显式配置以及记录独立行高仍优先于整表默认设置。

验收步骤：

1. 选择没有合计或备注的明细表，取消“表格外框 → 下”：最底部横线消失，其他三边和内部线保留；勾选后恢复。
2. 分别取消上、左、右，确认只改变对应外缘。切换表头、明细内部格子线，确认不改变外框与分隔线。
3. 隐藏表头与明细分隔线，确认两侧单元格都不再画这条线。添加自动合计或备注后，应出现该区域的内部格子线和前分隔线设置；删除这些内容后控件消失。
4. 用两层表头、纵向合并格和至少 45 条明细测试重复／不重复表头。每页外框和分隔线遵循所选状态，记录完整保留；保存重开后效果一致。
5. 打开有分区外框差异的旧模板，检查半选提示；修改文字外观，确认旧边框保留；点击对应外框边，确认只统一该边。恢复默认、撤销并预览，检查样式与设置一致。

### 表达式编辑与验收

长文本、明细表单格计算、列公式、筛行、整块显隐与颜色条件共用字段、函数、运算符和示例清单。字段按当前作用范围提供，本行字段与协议字段同名时优先使用本行字段；表达式直接写字段名，不写 `row.字段`。

- 长文本内容块间距：在正文编辑弹窗统一设置 pt 值，留空沿用默认空一行，0 表示分段但不额外留白。仅可见且非空内容块之间留距，首尾不加距；手动输入的空行保留。取消不写入模板，恢复默认会清除该配置。自定义间距按独立块渲染，跨页续文不保留首块前的间距。
- 长文本：在“编辑正文模板与条件内容”里点“设置显示条件”，配置整个内容块是否出现；点“插入 / 编辑表达式”，设置正文中的取值。每个块独立判断，多个块成立时都会出现，不等同于 if/else 分支链。
- 字段支持中文名／字段名搜索；函数支持名称／用途搜索与分类。点函数查看参数、返回类型和示例。条件参数默认用“字段＋比较方式＋比较值”配置，可加多条判断并选择且／或；复杂条件切换“公式编辑”。取值参数选择“字段值／固定值／计算表达式”；固定值再区分文字、数字、真／假，文字自动加引号，数字输入不接受公式。IF 填条件与两种结果，IFS 可继续添加条件与结果对，统计函数先选表再选字段。
- 函数参数填完整后点“插入函数”，写入表达式框，可继续用运算符、字段组合。参数切到“计算表达式”后，下方字段、运算符和函数插入到该参数的光标位置；嵌套函数弹窗注明目标参数，取消不改原参数。根据样例数据显示结果和错误；条件通常应返回真／假，旧有取值型条件仍按真假兼容。
- 正文表达式自动包裹 `{{…}}`，在光标处插入或替换选中文字。光标位于已有 `{{…}}` 内时，打开编辑器会带出原表达式，并替换完整原片段。取消弹窗不改正文；取消正文编辑不改模板。
- 单独引用已有字段时按原值计算，不再将金额或姓名转换为 `true`；显隐、筛行等布尔入口继续按真假判断。旧模板缺失布尔标记的兼容逻辑保留。

验收步骤：

1. 正文输入“甲方，奖励元”，把光标放在“甲方”后插入被征收人字段；在“元”前用 IF 构造奖励金额，确认前后文字完整保留、实时预览正确。
2. 在已有表达式中放置光标再点编辑，套用 `FORMAT_MONEY(IF(rewardTotal > 0, rewardTotal, 0), 2)`，确认替换原表达式且没有重复括号；应用到画布，保存后重开检查结果。
3. 内容块条件使用 `COUNT(rewardItems) > 0`；在数据源 JSON 中切换空／非空奖励表，确认整个块隐藏／显示。IF 的真假结果只改变所在片段。
4. 在单格计算、列公式和筛行分别打开“全部函数与字段”，搜索 IF、金额、合计。用 SUM 先选奖励表再选金额，确认生成 `SUM(rewardItems, "amount")`，换表时不沿用不匹配字段。
5. 筛行条件设为 `amount >= 20000`，检查匹配数量；统计函数使用原始数据源，不受打印筛行影响。输入错误函数或赋值语句时应显示错误且不能提交；取消、重新打开应恢复原配置。

6. 选择 IF，用“金额 >= 数量”并添加“名称不为空”生成组合条件。成立时选固定文字 `100 + 20`，确认结果原样显示；改成固定数字时该输入应报错。改选计算表达式，用字段与运算符插入 `quantity * unitPrice`，再插入 ROUND，确认嵌套函数只进入当前参数。取消嵌套编辑应保留原内容。

函数说明由 `runtime/print-expr-functions.ts` 维护，测试对照运行时函数全集并执行每个示例，防止界面目录与实际支持范围不一致。

pnpm exec vitest run apps/web-ele/src/views/biz/agreement/print
pnpm --filter @vben/web-ele typecheck

### 统一条件配置（规则与筛行）

- 规则区仅保留显示方式、已应用条件和样例结果。“按条件显示”打开统一条件窗口，标题标明当前元素；取消或关闭不会更改原规则，也不会把“始终隐藏”意外改为显示。公式失焦不提交。
- 元素显隐、内容块显隐和筛选打印行共用条件配置组件。条件配置支持字段比较、空值判断、多条件且／或，以及字段之间比较。公式编辑提供相同的字段、函数、运算符和示例目录；可用字段按当前场景分组。
- 旧条件能够无损拆解时回填为可视化配置，复杂逻辑、IN 等公式保留原文进入公式编辑。切换方式各自保留草稿；应用当前方式的内容。条件不完整、公式错误时禁止应用。
- 移除根据样例列生成的“隐藏金额为 0”等业务快捷按钮。样例数据只用于反馈保留行数，不代替用户配置真实业务规则。
- 显隐反馈“将显示／将隐藏”，筛行反馈“样例将打印 X / Y 行”。函数参数较多时窗口正文滚动，底部按钮始终可见。

验收：选中元素 → 规则 → 按条件显示，用“协议金额 > 0”应用；再次打开应回填条件。修改后取消应保留原规则。选中明细表 → 规则 → 更多条件，设置阈值并观察保留行数；取消不改变画布。切换公式编辑检查字段和函数目录，与长文本、计算中的目录一致。对字段间比较和混合逻辑，单列快捷筛选入口不得将其改写为固定文字。
